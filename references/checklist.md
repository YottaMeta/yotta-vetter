# 技能审查清单（四阶段）

## 第一阶段：来源检查

- [ ] 来源平台：技能市场 / GitHub / 其他
- [ ] 作者信誉：已知作者 / 新作者 / 匿名
- [ ] 下载量 / stars：高(>1000) / 中(100-1000) / 低(<100)
- [ ] 最后更新：最近(30 天内) / 较近(90 天内) / 很久以前
- [ ] 许可证：MIT / Apache / GPL / 其他 / 无
- [ ] 是否已归档（不再维护）

## 第二阶段：代码审查

- [ ] SKILL.md 存在，frontmatter name 与目录名一致
- [ ] 描述清晰、版本号有、目录结构合理
- [ ] 危险模式扫描：下载后执行 / 动态求值 / 数据外传 / 凭据访问 / 持久化 / 提权 / 混淆
- [ ] 安装钩子：npm 生命周期脚本、安装自定义命令类
- [ ] 隐藏字符：零宽字符、双向覆盖字符
- [ ] 依赖声明与必要性

## 第三阶段：权限评估

- [ ] 需要读取哪些文件（最小化？）
- [ ] 需要写入哪些文件（最小化？）
- [ ] 需要联网吗？目标地址可信吗？
- [ ] 需要执行哪些命令？需要提权吗？
- [ ] 可执行位 / 全局可写 / 符号链接是否异常

## 第四阶段：风险判定与决策

- [ ] 风险等级：低 / 中 / 高 / 极高
- [ ] 结论：SAFE TO INSTALL / REVIEW REQUIRED / INSTALL WITH CAUTION / DO NOT INSTALL
- [ ] 决策理由已记录
- [ ] 时间戳与审查者已记录
- [ ] 报告已保存（供后续追溯）

## 注意事项

1. 零信任：默认不信任，先验证再安装。
2. 最小权限：只授予功能所需的权限。
3. 持续监控：安装后仍关注行为与更新。
4. 及时更新：关注安全通告。
5. 备份恢复：重要系统做好备份。
